# Clock reference 037 frozen protocol

Implements the unchanged declared plan. Run the complete synthetic suite, verify
036's snapshot, then freeze this protocol, collector, driver, independent checker,
tests, predecessor evidence and pinned Windows runtime. Reserve an exclusive
sealed invocation before Windows status, HTTP requests or any SDK connection.

The Windows Time service query reports only existence/running status. It does
not establish synchronization. Each of the three exact declared URLs receives
one HEAD in a child process with verified default TLS; there are no redirects,
retries, alternate targets or response-body reads. Parent process deadlines cover
DNS as well as TLS/HTTP. At most 10 seconds per request and 30 seconds across the
request sequence; a deadline overrun fails closed. Only status and Date/Age/
Cache-Control survive. Duplicate, non-ASCII/control or oversized whitelisted
headers are rejected. Child/command/API exception text and private identity are
discarded. Date must be canonical IMF-fixdate GMT, status 2xx, Age absent or zero,
and Date inside local receipt bounds expanded by five seconds. Cache-Control is
preserved as cache context, not proof of freshness or origin clock accuracy.

All UTC receipts must be on 2026-10-06. Monotonic and UTC must move forward within
and between operations; UTC versus monotonic elapsed disagreement above five
seconds fails closed. Preserve each attempted request and its before/after
clocks, including failed attempts. Unusable references remain in the report.
At least two distinct declared hosts must qualify before connecting to an already
running exact MT5 terminal. Recheck actual DEMO/USD/Algo-off/connectivity/private
stable identity around the single EURUSD quote and at completion. No history,
symbol selection, terminal launch, login, setting changes, orders or retries.

For Date D and receipt bounds B..A, report coarse reference offset [D-A,D+1000-B]
milliseconds, uncertainty A-B+1000 milliseconds, and monotonic request duration.
The interval includes the whole round trip and one-second Date resolution;
it does not certify remote clock error or caching. Form the conservative envelope
of all usable offset intervals, without selecting the closest host. For quote Q
and its local receipt bounds QB..QA, raw-minus-local is [Q-QA,Q-QB]. Subtract the
offset envelope to obtain raw-minus-coarse-reference bounds. Overlap with
[-5000,+5000] is an observed coarse agreement; otherwise disagreement. Fewer
than two usable hosts or no safely accepted quote means insufficient evidence.
Quotes can be stale; disagreement does not identify broker/timezone/local cause.

Independent checking reparses originals and reconstructs these quantities rather
than calling production arithmetic. Check budgets, host order, header whitelist,
date/clock validity, quote acceptance, privacy schema and unchanged false gates.
All originals/reports use exclusive writes and SHA256 seals. No timestamp
normalization or performance eligibility change follows from this diagnostic.
