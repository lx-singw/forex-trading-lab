# Official MT5 help review —15 November2026

- [Platform Logs](https://www.metatrader5.com/en/terminal/help/start_advanced/journal):
  Experts is a program journal. Its Open command saves current entries and opens
  the log directory; Expert log files are under MQL5/Logs.
- [Market Watch — Downloading price history](https://www.metatrader5.com/en/terminal/help/trading/market_watch):
  The Symbols dialog provides Bars/Ticks history requests and CSV export. This is
  distinct from opening the program log folder or exporting the current Market
  Watch display.
