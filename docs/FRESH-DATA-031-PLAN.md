# Fresh-data readiness 031 — declared before observation

030 rejected universal protection as a robust improvement. Keep all strategies,
returns, annual gates and source exclusions intact. This stage prepares a route
to fresh chronological evidence; it runs no performance experiment.

Verify all 900 bindings, 864 archived members and 36 external inputs of the 030
snapshot. Inventory existing dataset directories and a fixed set of metadata
and failed eligibility reviews only. Read no historical price rows. Bind exact
metadata before inventory extraction. Existing 2024 research is reused, 2025
consumed and November–December 2026 reserved. Absence of a reviewed fresh dataset
does not prove no other source exists.

Implement a separate bounded current-quote receipt probe. Maximum 120 reads at
500ms spacing, approximately 60 seconds; one invocation and one exclusive output.
Only connect to an already-running installed MT5 terminal using the existing
isolated Windows Python environment. Never launch a terminal, log in, change
settings, select symbols, request history, place orders or deploy an EA. Missing
terminal/runtime is a preserved readiness outcome, not permission to launch it.

Check connected actual DEMO account mode and USD currency before and after each
EURUSD read. Reject REAL/CONTEST/unknown/disconnected, changed account identity,
or Algo Trading enabled. Use account identity only transiently for comparison,
never return or serialize it. Exact EURUSD must already be visible with EUR/USD
contract currencies. Export only whitelisted contract fields and raw time_msc,
bid/ask, local before/after UTC milliseconds, monotonic receipt bounds and poll
index. No account identifiers, server strings, credentials or full API objects.

Receipts must be on 2026-10-06 UTC, the current declared date, and monotonic;
stop on clock reversal, invalid quotes, decreasing raw timestamps or account
change. Repeat quote snapshots may be retained with a repeat marker. Stop and
preserve partial accepted observations on any guarded failure; never retry.
Recheck the account at completion. This is polling, so intervening ticks may be
missed. Raw API labels are not silently interpreted as UTC or shifted.
Reject raw labels more than 24 hours from the local receipt, preserving no
out-of-bound quote payload. The monotonic elapsed budget is 60 seconds; do not
start another read at the deadline and discard a read returned beyond it.
An in-flight API call cannot be forcibly bounded by this Python sampler.
Account identity comparison includes the private server value, without using
the server name to determine account type or exporting either value.

Report raw-label minus local-receipt ranges only. These are observations with
local-clock and stale-quote limitations, not historical timezone certification.
No conversion, fresh dataset eligibility, edge claim or annual gate change.
Current contract properties cannot certify historical fees, swap or fills.

Test long/short-independent price validity, demo/real/contest/unknown/disconnect,
account changes, Algo Trading, symbol/currency/visibility, missing/malformed
quotes, clock reversal/reserved dates, tied/repeated snapshots, decreasing source
times, completion guard, bounded read counts, partial preservation and privacy.
Run the complete regression suite before freezing source/tests/plan/input/output
paths and before any MT5 connection. The independent checker recomputes every
accepted observation and clock statistic, confirms no eligibility or execution,
and verifies the fixed metadata catalog against its bound originals.

If the terminal is unavailable, complete offline readiness work and state the
single next requirement: open the existing demo terminal with Algo Trading off.
Do not wait on a timer or install a scheduler. A later probe needs a separately
declared exclusive run and a current date/window, preserving this outcome.
Actual continuous quote collection, completeness/clock/cost qualification and
any strategy evaluation require separately declared follow-on stages.
